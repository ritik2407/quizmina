Overview

Executive Summary

QuizMinia represents a paradigm shift in digital testing, combining a highly modular backend with an intelligent personalization layer.

  • Objective: Dynamically personalizes evaluation questions in real-time, placing students in their optimal learning zone.
  • Backend Design: Powered by NestJS 11 and Sequelize ORM, implementing role-based modular code.
  • AI Capabilities: Connects to AWS Bedrock runtime running Google Gemma 3, providing adaptive grading, targeted question selection, and written performance insights.
  • Security: Features AES-256 encrypted session tokens, constant-time hashing, and paranoid model tracking.

Problem & Solution

The Personalization Gap

Traditional testing mechanisms treat all candidates equally, resulting in poor engagement and inaccurate competency assessment.

⚠️ The Problem

Static assessments cause frustration for lower-ability candidates and boredom for higher-ability ones, resulting in lost learning momentum.

✓ The Solution

Real-time difficulty steering. By matching the difficulty of the next question to the student's current proficiency, we keep them engaged in the "Zone of Proximal Development".

Architecture

System Architecture

QuizMinia adopts a standard clean Model-View-Controller (MVC) architecture with isolated feature modules in NestJS.

1. Presentation Layer (EJS + Chart.js)
Serves responsive pages, parses cookie-based sessions, and visualizes student learning curves.
2. Controller / Logic Layer (NestJS Controllers & Services)
Coordinates auth, quiz attempts, and schedules. Implements guards & validation pipes.
3. Data & AI Integrations (Sequelize ORM & AWS Bedrock Client)
MySQL database containing Soft-Deleted paranoid tables, connected to AWS Bedrock via SDK.

Data Model

Database Schema & Key Entities

The schema relies on well-defined foreign keys to track quiz progress and individual student profiles.

  • Roles: Three static roles (1: Admin, 2: Teacher, 3: Student) defining route permissions.
  • Users: Stores scores, attempts count, and `performanceProfile` (JSON details of strengths and weaknesses).
  • Quizzes & Questions: Quizzes host MCQ or short questions, each with a target difficulty score (0.0 to 1.0).
  • Attempts & Answers: Attempts track `currentDifficultyScore`. Answer records track each submission's accuracy and difficulty snapshot.

Security

Cookie-Based Custom Sessions

The application secures session cookies directly on the server side using custom encryption rather than storing sensitive payloads in plaintext.

  • Middleware Verification: `RequestMiddleware` intercepts cookies, decrypts them using AES-256-CBC and the project's secret `APP_KEY`.
  • Session Persistence: Decrypted session strings resolve to `Token` instances in the database, verifying active logins.
  • Token Binding: On logout, the token's `userId` binding is set to `null` while keeping anonymous tracking intact.

Security

Cryptographic Hashing

Password hashing relies on industry-strength algorithms to secure user accounts.

  • Algorithm: PBKDF2 with SHA-512.
  • Salting: 32 cryptographically secure random bytes generated uniquely per user.
  • Iterations: 1,000 passes to prevent hardware brute-forcing.
  • Constant-Time Verification: Uses `crypto.timingSafeEqual` (via `Buffer.equals`) to defeat timing analysis.

AI Engine

The Adaptive Engine Concept

Rather than serving a linear sequence of questions, QuizMinia adjusts difficulty dynamically based on current student performance.

📊 Scoring Ranges

• 0.00 – 0.35: Easy (Starter questions)

• 0.36 – 0.65: Medium (Intermediary content)

• 0.66 – 1.00: Hard (Advanced questions)

🎯 Selection Logic

The engine sorts remaining unanswered questions by the absolute difference: `|question.difficultyScore - currentDifficultyScore|` and delivers the closest match.

AI Engine

AWS Bedrock Integration

Bedrock is utilized to run LLM operations via structured system prompts.

  • Inference Service: Uses `google.gemma-3-4b-it` hosted on AWS Bedrock.
  • Payload Structure: The prompt submits the student's current streaks, current difficulty, and correct/incorrect answer details.
  • Structured Responses: Bedrock evaluates the status and returns a JSON package containing the next target difficulty and personalized feedback.

AI Engine

Rule-Based Fallback

To prevent system outages if AWS Bedrock is unreachable or rate-limited, QuizMinia automatically switches to a rule-based engine.

Condition Difficulty Adjustment
Correct streak ≥ 3 +0.20 (Significant increase)
Correct streak = 2 +0.10 (Moderate increase)
Single correct response +0.05 (Incremental increase)
Wrong streak ≥ 3 -0.20 (Significant decrease)
Wrong streak = 2 -0.10 (Moderate decrease)
Single wrong response -0.05 (Incremental decrease)
